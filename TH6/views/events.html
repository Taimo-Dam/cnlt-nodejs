⚡ EventEmitter

Minh họa on(), emit(), once() — truyền dữ liệu và callback trong event

emitter.on()

pageVisit Event

Lắng nghe nhiều lần. Mỗi lần trigger sẽ tăng bộ đếm.

// Lắng nghe event 'pageVisit' emitter.on('pageVisit', (data) => { visitCount++; logEvent(`Visit: ${data.page}`); });
__VISIT_COUNT__
Lượt trigger pageVisit

emitter.emit() + data

postCreated Event

Truyền dữ liệu vào event (title, author) và xử lý trong callback.

// emit với dữ liệu emitter.emit('postCreated', { title: 'Bài viết mới', author: 'Admin' });
emitter.once()

serverStart Event

Chỉ chạy 1 lần duy nhất khi server khởi động.

// Chỉ chạy 1 lần! emitter.once('serverStart', (data) => { log(`Server at port ${data.port}`); });
✅ once('serverStart') đã chạy 1 lần khi server khởi động
