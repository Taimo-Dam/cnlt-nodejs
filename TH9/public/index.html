📝 Phân tích kết quả
Hãy gửi "3 đồng thời" cho cả hai loại để quan sát sự khác biệt.
Sync: Request 2 và 3 phải chờ request 1 hoàn toàn xong mới bắt đầu.
Async: Cả 3 request bắt đầu gần như cùng lúc, kết thúc gần như cùng nhau sau ~2 giây.
